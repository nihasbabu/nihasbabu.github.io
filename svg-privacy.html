Privacy Policy – SVG Drive Sync

Last updated: 23 November 2026

SVG Drive Sync ("the app") is an internal tool of Smart Value General Contracting LLC. This policy explains how it handles Google user data.

Who can use it

Only the company's own staff, using the company's own Google account. It is not offered to the public.

What data it accesses

With the account owner's permission, the app accesses files in the company's own Google Drive.

How the data is used

Only to make the company's own files available on the company's own computer. Data is not used for advertising, profiling or any other purpose.

Storage and sharing

Files and the access token are stored only on the company's own computer. Google data is not sold, rented or shared with third parties.

Limited use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions.
